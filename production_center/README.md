# Инструмент распределения сотрудников между производственными центрами

## Порядок запуска
- Собрать .jar (например, командой mvn package, параметры сборки уже настроены в файле pom.xml, имя файла в данном случае будет production_center-1.jar)
- Запустить команду java -jar <путь к файлу .jar>

## Особенности программы
Программа представляет собой консольное приложение. После запуска программа запросит путь к xlsx-файлу с входными данными.

В программе подразумевается, что в Excel-файлах с входными данными листы с информацией названы соответствующе, как в примере: "Scenario", "ProductionCenter", "Connection". В противном случае программа не сможет распознать данные.

В коде программы встроены ограничения на ожидаемую размерность данных исходя из соответствующей информации в задании.
- Количество сотрудников до 40
- Количество производственных центров до 20
- Максимальное время на обработку одной детали 10 минут
- Количество деталей до 2000

В случае нарушения данных условий программа выдаст сообщение об ошибке.

Результат работы программы сохраняется в csv-файл с именем *result.csv*. Пример визуализации результатов с помощью приложенного в задании скрипта находится в файле *visualization.pdf*
